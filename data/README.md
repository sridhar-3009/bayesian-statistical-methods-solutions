# Data used by the solutions

| File | Used in | Source |
|---|---|---|
| `election_2008_2016.RData` | Ch. 4 Ex. 3 | Book website, Chapter 4 datasets: <https://bayesian-statistical-methods.wordpress.ncsu.edu/datasets/> |
| `guns.Rdata` | Ch. 4 Ex. 4 | Book website, Chapter 4 datasets (originally Kalesan et al., 2016) |
| `global_mean_temp.RData` | Ch. 4 Ex. 10 | Book website (originally NASA GISTEMP, <https://data.giss.nasa.gov/gistemp/>) |
| `titanic_train.csv` | Ch. 4 Ex. 5 | `titanic_train` from the CRAN package **titanic** (columns Survived, Pclass, Sex, Age) |
| `sophia.csv` | Ch. 4 Ex. 9 | CRAN package **babynames** (US Social Security Administration): girls named Sophia, years after 1950 |
| `gambia.csv` | Ch. 4 Ex. 8 | `gambia` dataset from the CRAN package **geoR** (Thomson et al., 1999) |

Datasets that ship with R (`MASS::Boston`, `MASS::galaxies`) are loaded directly in the scripts.
