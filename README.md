# Bayesian Statistical Methods: Worked Solutions

Detailed, step-by-step solutions to the end-of-chapter exercises in

> **Brian J. Reich & Sujit K. Ghosh, *Bayesian Statistical Methods: With Applications to Machine Learning*, 2nd ed., CRC Press.**

Each chapter is a typeset LaTeX/PDF write-up with the R code that reproduces every number and figure.

## How each solution is laid out

Every exercise follows the same six blocks, so you always know where to look:

| Block | What it contains |
|---|---|
| 📘 **Exercise** | the exact problem statement from the book |
| 💬 **In plain words** | what the problem is really asking |
| 💡 **Key idea** | the concept or formula needed before starting |
| ✏️ **Solution** | a step-by-step derivation, with every step justified |
| ✅ **Answer** | the final result, boxed |
| ⚠️ **Takeaway** | intuition, sanity checks and common mistakes |

Each chapter PDF also opens with an **Answers at a glance** page.

│   ├── code/ch01.R       reproduces all numbers and figures (hand-written samplers)

## Building it yourself

You need R (base R only, no extra packages) and a TeX distribution (TeX Live or MacTeX).

```bash
make ch01     # run the R code, then compile ch01/ch01.pdf
make all      # every chapter
make clean    # remove LaTeX build files
```

## Notes

- **JAGS** exercises: every model is also fitted with a hand-written sampler in base R, so all numbers can be reproduced without JAGS. The JAGS scripts (`chXX/code/chXX_jags.R`) run automatically on GitHub Actions; their output is downloadable from the *Actions* tab (artifact `jags-output`) and is quoted in the PDFs.
- Where a figure or table is missing from the source text, the solution says so and states exactly which data were used. For example, Exercise 1.25 uses the published Moderna trial data.
- Spotted a mistake or have a cleaner solution? Please open an issue.
